# Разработка

Из каталога пакета, только Python 3.12:

```bash
ma tools
ma tests
```

Makeapp читает матрицу из [workflow](../.github/workflows/python-package.yml).
CI запускает pytest без makeapp; не собирает приложения и не публикует Releases.
Общий набор проверок офлайн: процессы Git, iroll и gh подменены;
тесты не требуют SDK, компиляторов, сети, оборудования или прав администратора.
Успех этих проверок не подтверждает работу на стике.

Пакет — `src/iboxed/`, тесты его модулей находятся непосредственно в `tests/`:

- `config.py` — конфиг и матрица;
- `build.py` — снимок коммитов, запуск iroll, SD-архивы и манифест;
- `publish.py` — неизменяемый тег и draft-публикация через gh;
- `process.py` — запуск внешних команд и отмена;
- `cli.py` — только согласованные аргументы, сообщения и коды завершения.

Краткий список лицензий — [THIRD_PARTY.txt](../THIRD_PARTY.txt).

Проверка упаковки:

```bash
uv build
```

Wheel содержит только Python-пакет, метаданные и лицензию; sdist также тесты,
документацию, конфиг и workflow. Сабмодули, SDK, NOR, рабочие деревья,
бинарные комплекты и uv.lock в дистрибутивы не входят.
Для реальной сборки нужен отдельный Git checkout с инициализированными сабмодулями;
sdist не заменяет интеграционный репозиторий.

Установка CLI описана в [README](../README.md#подготовка).
Проверяйте `iboxed --help` из постороннего каталога после изменения точки входа.
Линтеры и форматтеры запускайте только по прямой просьбе владельца.
